# Paper 사용 안내

Paper는 Eclipse와 Spring Tools의 코드 편집기에 공책 줄, 모눈, 종이 질감을 더하는 무료 플러그인입니다. 선과 배경을 원하는 색과 간격으로 꾸미고, 밝은 테마와 어두운 테마에 맞는 종이색을 각각 지정할 수 있습니다.

<img src="docs/images/light-editor.png" alt="밝은 종이색에 공책 줄과 구겨진 종이 질감을 적용한 편집기" width="48%"> <img src="docs/images/dark-editor.png" alt="어두운 종이색에 같은 공책 줄과 질감을 적용한 편집기" width="48%">

왼쪽은 라이트 테마, 오른쪽은 다크 테마의 사용 예입니다. 공책·모눈 등 12가지 배경, 10가지 선 모양, 35가지 종이 질감을 조합할 수 있습니다.

이 안내는 **Windows용 Eclipse와 Spring Tools**를 기준으로 합니다. Java 편집기, Text Editor, XML/JSP 편집기의 소스 페이지에서 사용할 수 있습니다. 자세한 버전 정보는 [사용 환경](#사용-환경)을 확인하세요.

## 설치

아래 세 가지 방법 중 하나를 선택해 설치합니다. Eclipse Marketplace 메뉴가 있다면 첫 번째 방법을 사용하세요.

### Eclipse Marketplace에서 설치

1. Eclipse 또는 Spring Tools에서 **Help → Eclipse Marketplace…**를 엽니다.
2. 검색창에 **`paper`**를 입력하고 검색합니다.
3. 검색 결과에서 게시자가 **pinnpublic**인 **Paper**를 찾아 **Install**을 누릅니다.
4. 설치할 항목을 확인하고 **Next**를 눌러 진행합니다.
5. 라이선스를 확인한 뒤 동의하고 **Finish**를 누릅니다.
6. 재시작 안내가 나오면 IDE를 재시작합니다.

플러그인 소개와 화면 예시는 [Paper 마켓플레이스 페이지](https://marketplace.eclipse.org/content/paper)에서도 볼 수 있습니다.

### 업데이트 사이트 주소로 설치

Marketplace 메뉴가 없거나 검색으로 설치하기 어려울 때 사용할 수 있습니다.

1. **Help → Install New Software…**를 엽니다.
2. **Add…**를 누르고 **Name**에 `Paper`, **Location**에 아래 주소를 입력합니다.

   ```text
   https://pinnpublic.github.io/eclipse-paper/updates/
   ```

3. **Add**를 누르고 목록이 표시되면 **Paper**를 선택합니다.
4. **Next**를 눌러 진행하고, 라이선스에 동의한 뒤 **Finish**를 누릅니다.
5. 설치가 끝나면 IDE를 재시작합니다.

### ZIP 파일로 설치

1. [Paper 1.3.13 설치 ZIP](https://github.com/pinnpublic/eclipse-paper/releases/download/v1.3.13/paper-update-site-1.3.13.zip)을 다운로드합니다. 압축은 풀지 않습니다.
2. IDE에서 **Help → Install New Software… → Add… → Archive…**를 엽니다.
3. 다운로드한 `paper-update-site-1.3.13.zip`을 선택하고 **Add**를 누릅니다.
4. 목록에서 **Paper**를 선택하고 **Next**를 눌러 설치를 진행합니다.
5. 라이선스에 동의하고 설치를 완료한 뒤 IDE를 재시작합니다.

다른 버전의 설치 파일은 [릴리즈 목록](https://github.com/pinnpublic/eclipse-paper/releases)에서 다운로드할 수 있습니다.

## 처음 사용하기

처음 설치하면 기본 공책 배경과 가로줄이 켜져 있습니다. Java 파일이나 텍스트 파일을 열어 확인한 뒤, 아래 순서로 취향에 맞게 바꿔 보세요.

1. **Window → Preferences**를 엽니다.
2. 검색창에 `Paper` 또는 `노트`를 입력하고 **Paper / 노트 배경**을 선택합니다. 메뉴에서 직접 찾으려면 **General → Editors → Text Editors → Paper / 노트 배경**으로 이동합니다.
3. **소스 편집기에 노트 표시**가 선택되어 있는지 확인합니다.
4. **선** 탭에서 글줄 아래에 표시할 선을, **배경** 탭에서 종이의 색·무늬·질감을 고릅니다.
5. 아래쪽 **미리보기**에서 모양을 확인합니다.
6. **Apply**를 눌러 편집기에 적용하거나, **Apply and Close**를 눌러 적용 후 설정 창을 닫습니다.

예를 들어 모눈 배경을 사용하려면 **배경 → 배경 종류 → 모눈**을 선택합니다. 모눈 위에 가로줄을 따로 표시하고 싶지 않다면 **선 → 모든 글줄 아래에 선 표시**를 해제한 뒤 적용합니다.

## 선과 줄 간격 조절

설정 화면의 **선** 탭에서 조절합니다. **모든 글줄 아래에 선 표시**를 켜면 각 글줄 아래에 가로줄이 나타납니다.

| 항목 | 사용 방법 |
|---|---|
| 선 종류 | 실선, 가는 점선, 둥근 점선, 짧은 파선, 긴 파선, 일점쇄선, 이점쇄선, 이중선, 삼중선, 물결선 중 선택합니다. |
| 선 색상 | 가로줄의 색을 선택합니다. |
| 두께 | 선의 굵기입니다. 글자 높이의 1~25%로 설정합니다. |
| 텍스트와 선 간격 | 글자 아래에서 선이 그려지는 위치입니다. 글자 높이의 -50~100%로 설정하며, 값을 줄이면 선이 글자 쪽으로 올라갑니다. |
| 추가 줄 간격 | 글줄 사이에 더하는 여백입니다. 글자 높이의 0~200%로 설정하며, 기본값은 30%입니다. 0으로 설정하면 편집기의 기본 줄 간격을 사용합니다. |
| 선 진하기 | 1~100%로 설정합니다. 값이 작을수록 선이 연해집니다. |
| 현재 줄 강조 불투명도 | 커서가 있는 줄의 강조 배경이 얼마나 진하게 보일지 정합니다. 0%는 투명, 100%는 불투명이며 기본값은 50%입니다. |

**글자가 선에 너무 붙어 보이면** `텍스트와 선 간격`을 늘립니다. **글줄 사이가 좁아 보이면** `추가 줄 간격`을 늘립니다. 두 설정은 별개이며, 가로줄을 꺼도 추가 줄 간격은 적용됩니다.

## 배경과 종이 질감 꾸미기

설정 화면의 **배경** 탭에서 조절합니다. 배경 종류는 종이에 들어갈 무늬를, 종이 질감은 종이 표면의 느낌을 정합니다. 두 가지를 함께 사용할 수 있습니다.

### 배경 무늬 선택

**배경 종류**에서 원하는 모양을 선택합니다.

| 종류 | 모양 |
|---|---|
| 단색 | 배경 무늬 없이 종이색을 표시합니다. |
| 공책 | 왼쪽에 여백을 구분하는 세로선이 있는 배경입니다. 글줄 아래 가로줄은 **선** 탭에서 켜고 끕니다. |
| 모눈, 촘촘한 모눈, 공학용 모눈 | 사각 격자 배경입니다. |
| 점 격자, 십자 격자 | 점 또는 작은 십자 표시를 일정한 간격으로 배치합니다. |
| 세로줄 | 세로 방향으로 선을 반복합니다. |
| 등각 격자, 마름모 격자 | 사선이 교차하는 격자 배경입니다. |
| 원고지 | 글자 칸이 나뉜 원고지 모양입니다. |
| 코넬 노트 | 왼쪽 메모 여백을 나누는 세로선과 요약 영역을 구분하는 가로선이 있는 배경입니다. |

무늬를 선택한 뒤 아래 항목으로 조절합니다.

| 항목 | 사용 방법 |
|---|---|
| 무늬 색상 | 격자·점 등 배경 무늬의 색을 선택합니다. 공책의 여백 세로선은 붉은 계열의 고정 색상을 사용합니다. |
| 무늬 크기 | 무늬의 간격과 크기를 줄 높이의 50~300%로 설정합니다. |
| 무늬 진하기 | 1~100%로 설정합니다. 값이 작을수록 무늬가 연해집니다. |

공책과 코넬 노트의 여백 세로선은 편집기의 탭 간격에 맞춰 배치됩니다. 편집기에서 탭 크기를 바꾸면 세로선 위치도 달라집니다.

### 종이색과 테마 설정

Eclipse 테마의 배경색을 그대로 사용하려면 **편집기 테마의 배경색 사용**을 켭니다.

직접 고른 종이색을 사용하려면 다음과 같이 설정합니다.

1. **편집기 테마의 배경색 사용**을 끕니다.
2. **종이 배경색 (라이트 테마)**에서 밝은 테마에 쓸 색을 고릅니다.
3. **종이 배경색 (다크 테마)**에서 어두운 테마에 쓸 색을 고릅니다.
4. **Apply** 또는 **Apply and Close**를 누릅니다.

Eclipse 테마를 전환하면 해당 테마에 지정한 종이색이 적용됩니다. 선 모양·무늬·질감·간격 설정은 두 테마에서 공통으로 사용합니다.

### 종이 질감 적용

1. **종이 질감**에서 원하는 재질을 선택합니다.
2. **질감 진하기**를 0~100%로 조절하며 미리보기에서 확인합니다. 0%는 질감을 숨깁니다.
3. **Apply** 또는 **Apply and Close**를 누릅니다.

질감을 선택하면 테마 배경색 사용이 꺼지고, 선택한 재질에 맞는 라이트·다크 종이색이 함께 설정됩니다. 종이색을 직접 바꾸려면 **질감을 먼저 선택한 뒤 색을 지정**하세요.

질감을 없애려면 **종이 질감 → 없음**을 선택합니다. 종이색도 Eclipse 테마에 맞추고 싶다면 **편집기 테마의 배경색 사용**을 다시 켭니다.

## 글자 크기와 미리보기

설정 화면의 **글꼴 확대/축소**는 미리보기의 글자 크기만 바꿉니다. 50~200% 배율에서 선과 배경이 어떻게 보이는지 확인할 수 있습니다.

실제 파일의 글자 크기는 Eclipse의 편집기 글꼴 설정이나 편집기 확대·축소 기능으로 바꿉니다. 글자 크기를 바꾸면 선과 배경 무늬도 그 크기에 맞춰 조절됩니다. 종이 질감은 같은 크기로 유지됩니다.

## 끄기와 기본 설정 복원

**Paper를 잠시 끄려면** 설정 화면에서 **소스 편집기에 노트 표시**를 해제하고 **Apply**를 누릅니다. 다시 사용하려면 같은 항목을 선택하고 적용합니다.

**가로줄만 숨기려면** **선** 탭의 **모든 글줄 아래에 선 표시**를 해제합니다. 종이색·배경 무늬·질감은 계속 사용할 수 있습니다.

**설정을 처음 상태로 되돌리려면** Paper 설정 화면의 **Restore Defaults**를 누른 뒤 **Apply** 또는 **Apply and Close**를 누릅니다. 직접 지정한 색과 간격도 기본값으로 돌아갑니다.

## 자주 묻는 질문

### Eclipse Marketplace 메뉴가 없어요

[업데이트 사이트 주소](#업데이트-사이트-주소로-설치) 또는 [ZIP 파일](#zip-파일로-설치)로 설치하세요.

### 설치했는데 배경이 보이지 않아요

설치 후 IDE를 재시작했는지 확인하세요. Paper 설정에서 **소스 편집기에 노트 표시**를 켜고 **Apply**를 누릅니다. Java 편집기나 Text Editor에서 확인하고, XML/JSP 편집기에서는 **Source** 페이지를 선택하세요.

### 종이색을 바꿀 수 없어요

**배경** 탭의 **편집기 테마의 배경색 사용**을 끄면 라이트·다크 종이색을 직접 지정할 수 있습니다.

### 배경을 단색으로 골랐는데 가로줄이 남아 있어요

가로줄은 배경 무늬와 별도로 설정합니다. **선** 탭에서 **모든 글줄 아래에 선 표시**를 해제하세요. 종이 표면의 질감도 없애려면 **배경 → 종이 질감 → 없음**을 선택합니다.

### 커서가 있는 줄에서 종이 질감이 가려져요

**선** 탭의 **현재 줄 강조 불투명도**를 낮추세요. 0%로 설정하면 현재 줄의 강조 배경이 투명해집니다.

위 방법으로 해결되지 않으면 [문의 페이지](https://github.com/pinnpublic/eclipse-paper/issues)에 사용 중인 IDE 버전과 문제가 보이는 화면을 함께 남겨 주세요.

## 삭제

1. **Help** 메뉴에서 **About Eclipse IDE** 또는 사용 중인 Spring Tools의 **About** 항목을 엽니다.
2. **Installation Details → Installed Software**를 선택합니다.
3. 목록에서 **Paper**를 선택하고 **Uninstall…**을 누릅니다.
4. 안내에 따라 삭제를 완료한 뒤 IDE를 재시작합니다.

## 사용 환경

Windows에서 아래 환경의 동작을 확인했습니다.

| IDE | Eclipse 기반 버전 | Java |
|---|---|---|
| Spring Tool Suite 3.9.18 | 4.21 | 11 |
| Eclipse IDE 2026-06 | 4.40 | 21 |
| Eclipse IDE 2026-09 | 4.41 | 21 |
| Spring Tools for Eclipse 5.3.0 | 4.40 | 21 |

Paper는 Eclipse 4.21 이상, Java 11 이상을 요구합니다. IDE 자체에서 더 높은 Java 버전을 요구하는 경우에는 해당 IDE의 요구 사항을 따릅니다.

적용 대상은 Java 편집기, Text Editor, XML/JSP 편집기의 소스 페이지입니다. 별도의 화면 구조를 사용하는 다른 플러그인의 편집기에는 적용되지 않을 수 있습니다.
