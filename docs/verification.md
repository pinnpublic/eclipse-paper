# 검증 범위

Windows의 실제 `org.eclipse.ui.ide.workbench`를 별도 구성·워크스페이스에서 실행해 확인했습니다. 사용자 IDE의 설치 설정을 바꾸는 방식으로 시험하지 않습니다.

| 기준 버전 | 검사 |
|---|---|
| 1.3.3 | STS 3: 318개, Eclipse: 318개, STS 5: 317개 전체 검사 통과 |
| 1.3.4 | 세 IDE 각각 146개 테마·줄 번호·오류 마커·창 복원 검사 통과 |
| 1.3.5 | 세 IDE 각각 149개 검사 통과: Paper 이름·MIT 패키징·테마·오류 마커·창 복원. p2 수집·해시도 확인했습니다. 렌더링 로직은 1.3.4와 같습니다. |

환경은 STS 3.9.18 / Eclipse 4.21 + Java 11, Eclipse 4.40 + Java 21, Spring Tools 5.3.0 / Eclipse 4.40 + Java 21입니다.

## 확인한 항목

- Java/Text/XML/JSP 소스 편집기 연결, 첫 그리기, 여러 페이지와 여러 창.
- 선 종류·배경 무늬·종이 질감·투명도·독립 줄 간격·탭 폭·글꼴 확대·가로/세로 스크롤.
- 줄 번호와 본문의 픽셀 기준선, 마우스 전달, 실제 오류 마커의 추가/제거.
- 라이트/다크 테마 전환, 현재 줄 강조, 미리보기·적용·기본값 복원·취소.
- 최소화/복원, 배경 캐시 유지, 유휴 자기 재그리기, 이미지 해제.
- p2 feature 조회, plugin/feature 실제 수집, 배포 JAR와 수집 파일의 SHA-256 일치.

번호 가장자리는 네이티브 숫자를 단색 배경에서 얻은 뒤 실제 종이와 합성합니다. 단색 테두리를 줄이고 글자 내부·기준선은 유지하는지 별도로 검사합니다.

물리 데스크톱 GC 캡처에 격리 시험 창이 잡히지 않아, 모든 순간의 화면 깜빡임/DWM 합성 결과를 직접 검증했다고 주장하지 않습니다. 관련 비교는 SKIP으로 기록하고 네이티브 렌더링·이벤트·기하 및 자원 상태를 검사합니다.

현재 소스의 검사는 `test-ruler.ps1`, `test-rendering.ps1`, `test-runtime.ps1`로 재현할 수 있습니다. 원시 개발 로그·과거 스크린샷·동결 보관본은 로컬 `local/`와 `releases/`에 남기고 Git에서 제외합니다.
